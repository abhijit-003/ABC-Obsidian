# 1. Functions

Functions are reusable blocks of code that perform a specific task. They help reduce code duplication and improve readability.

## Syntax

```python
def function_name(parameters):
    # function body
    return value
```

Example

```python
def add(a, b):
    return a + b
```

Calling a function

```python
result = add(10, 20)
print(result)
```

Output

```
30
```

---

## Function Without Return

If a function does not explicitly return anything, it returns `None`.

```python
def greet():
    print("Hello")

greet()
```

Output

```
Hello
```

---

## Function With Parameters

```python
def greet(name):
    print(f"Hello {name}")

greet("Abhi")
```

Output

```
Hello Abhi
```

---

## Returning Multiple Values

Python can return multiple values from a function.

```python
def calculate(a, b):
    return a + b, a - b

sum_value, difference = calculate(20, 10)

print(sum_value)
print(difference)
```

Output

```
30
10
```

Internally, Python returns these values as a tuple.

---

## Default Arguments

Default values are used if an argument is not provided.

```python
def greet(name="Guest"):
    print(name)

greet()
greet("Abhi")
```

Output

```
Guest
Abhi
```

---

## Keyword Arguments

Arguments can be passed using parameter names.

```python
def student(name, age, country):
    print(name, age, country)

student(age=24, country="India", name="Abhi")
```

Advantages

- Order doesn't matter
- Improves readability

---

## Positional Arguments

Arguments are assigned according to their position.

```python
def student(name, age):
    print(name, age)

student("Abhi", 24)
```

Order matters.

---

## Mixing Positional and Keyword Arguments

```python
def student(name, age):
    print(name, age)

student("Abhi", age=24)
```

Rule

- Positional arguments must come first.
- Keyword arguments come afterwards.

---

## Variable-Length Arguments (`*args`)

Used when the number of arguments is unknown.

```python
def add(*numbers):
    print(numbers)

add(1, 2, 3, 4)
```

Output

```
(1, 2, 3, 4)
```

`*args` stores arguments inside a tuple.

Example

```python
def add(*numbers):
    total = 0

    for number in numbers:
        total += number

    return total

print(add(1, 2, 3, 4, 5))
```

Output

```
15
```

---

## Keyword Variable Arguments (`**kwargs`)

Stores named arguments inside a dictionary.

```python
def info(**details):
    print(details)

info(name="Abhi", age=24)
```

Output

```python
{'name': 'Abhi', 'age': 24}
```

Accessing values

```python
def info(**details):
    print(details["name"])

info(name="Abhi", age=24)
```

## Scope

### Local Scope

Variables created inside a function exist only inside that function.

```python
def fun():
    x = 10

print(x)
```

Output

```
NameError
```

---

### Global Scope

Variables declared outside functions are global.

```python
x = 100

def fun():
    print(x)

fun()
```

Output

```
100
```

---

### Modifying Global Variables

```python
x = 10

def fun():
    global x
    x = 20

fun()

print(x)
```

Output

```
20
```

Avoid using `global` unless absolutely necessary.

---

## Nested Functions

Functions can be defined inside other functions.

```python
def outer():

    def inner():
        print("Hello")

    inner()

outer()
```

Output

```
Hello
```

Nested functions are commonly used in decorators and closures.

---

## Recursion

A recursive function calls itself.

```python
def factorial(n):

    if n == 1:
        return 1

    return n * factorial(n - 1)

print(factorial(5))
```

Output

```
120
```

Every recursive function should have a base case.

# 2. Lambda Functions

Lambda functions are anonymous one-line functions.

Syntax

```python
lambda arguments : expression
```

Example

```python
square = lambda x: x * x

print(square(5))
```

Output

```
25
```

---

Multiple Parameters

```python
add = lambda a, b: a + b

print(add(10, 20))
```

Output

```
30
```

---

Sorting Example

```python
students = [
    ("Abhi", 24),
    ("Rahul", 21),
    ("Amit", 22)
]

students.sort(key=lambda x: x[1])

print(students)
```

---

## map()

Applies a function to every element.

```python
numbers = [1, 2, 3]

result = list(map(lambda x: x * x, numbers))

print(result)
```

Output

```
[1, 4, 9]
```

---

## filter()

Returns only elements satisfying a condition.

```python
numbers = [1, 2, 3, 4, 5, 6]

even = list(filter(lambda x: x % 2 == 0, numbers))

print(even)
```

Output

```
[2, 4, 6]
```

# 5. __name__

Every Python file has a special variable named `__name__`.

```python
print(__name__)
```

When executed directly

```
__main__
```

When imported

```
module_name
```

Best Practice

```python
def main():
    print("Application Started")

if __name__ == "__main__":
    main()
```

This ensures the code only runs when the file is executed directly.

# 7. Exception Handling

Exceptions prevent a program from crashing unexpectedly.

Syntax

```python
try:
    ...
except:
    ...
finally:
    ...
```

---

## try-except

```python
try:
    x = 10 / 0
except ZeroDivisionError:
    print("Cannot divide by zero")
```

Output

```
Cannot divide by zero
```

---

## Multiple Exceptions

```python
try:
    pass
except ValueError:
    pass
except ZeroDivisionError:
    pass
```

---

## Generic Exception

```python
try:
    pass
except Exception as e:
    print(e)
```

---

## else

Runs only if no exception occurs.

```python
try:
    print("Success")
except:
    pass
else:
    print("No Error")
```

Output

```
Success
No Error
```

---

## finally

Always executes.

```python
try:
    print("Working")
finally:
    print("Finished")
```

Output

```
Working
Finished
```

Common Uses

- Closing files
- Closing database connections
- Releasing resources

---

## raise

Used to manually throw an exception.

```python
age = -5

if age < 0:
    raise ValueError("Age cannot be negative")
```

Output

```
ValueError: Age cannot be negative
```

---

## Custom Exceptions

```python
class AgeException(Exception):
    pass

raise AgeException("Invalid Age")
```

Useful for application-specific errors.

# 8. Common Mistakes

## 1. Mutable Default Arguments

❌ Wrong

```python
def add_item(item, items=[]):
    items.append(item)
    return items

print(add_item("A"))
print(add_item("B"))
```

Output

```
['A']
['A', 'B']
```

The same list is reused across calls.

---

✅ Correct

```python
def add_item(item, items=None):

    if items is None:
        items = []

    items.append(item)

    return items
```

---

## 2. Importing Everything

Avoid

```python
from math import *
```

Prefer

```python
import math
```

or

```python
from math import sqrt
```

---

## 3. Catching Every Exception

Avoid

```python
except:
    pass
```

It hides bugs.

Prefer

```python
except ValueError:
    ...
```

or

```python
except Exception as e:
    print(e)
```

---

## 4. Overusing Lambda

Use lambda only for short, simple expressions.

For complex logic, use a normal function.
