# 1. Iterables & Iterators

## Iterable

An **iterable** is any object that can be traversed one element at a time.

Common iterables:
- list
- tuple
- string
- set
- dictionary
- file
- range()

Example

```python
numbers = [10, 20, 30]

for num in numbers:
    print(num)
```

The `for` loop internally creates an iterator and repeatedly calls `next()`.

---

## Iterator

An **iterator** is an object that keeps track of the current position while iterating.

Create an iterator using `iter()`.

```python
numbers = [10, 20, 30]

it = iter(numbers)

print(next(it))
print(next(it))
print(next(it))
```

Output

```
10
20
30
```

Calling `next()` again raises

```
StopIteration
```

### Important

Every iterator is iterable.

Not every iterable is an iterator.

---

## Useful Built-in Functions

```python

```

# 2. Generators

A generator is a special type of function that produces values **one at a time** instead of returning everything at once.

Normal Function

```python
def numbers():
    return [1, 2, 3]
```

Everything is stored in memory.

---

Generator

```python
def numbers():
    yield 1
    yield 2
    yield 3
```

Each value is produced only when requested.

---

Usage

```python
for num in numbers():
    print(num)
```

Output

```
1
2
3
```

---

## Why use Generators?

Imagine generating numbers from 1 to 1 billion.

Using a list

```python
numbers = list(range(1000000000))
```

This consumes a huge amount of memory.

Using a generator

```python
def generate():
    for i in range(1000000000):
        yield i
```

Only one value exists in memory at any moment.

---

## Advantages

- Memory Efficient
- Lazy Evaluation
- Faster for huge datasets
- Infinite sequences are possible

---

## Generator Object

```python
gen = numbers()

print(next(gen))
print(next(gen))
```

# 3. Generator Expressions

Generator Expressions are similar to List Comprehensions but use parentheses.

List Comprehension

```python
squares = [x*x for x in range(5)]
```

Output

```python
[0,1,4,9,16]
```

---

Generator Expression

```python
squares = (x*x for x in range(5))
```

Output

```
<generator object>
```

To retrieve values

```python
for value in squares:
    print(value)
```

---

## When to Use

Use Generator Expressions when

- Processing huge files
- Reading data streams
- Working with millions of records

# 4. Decorators

A decorator adds extra functionality to an existing function without modifying its source code.

Think of it as wrapping a function.

```
Original Function

↓

Decorator

↓

Enhanced Function
```

---

## Basic Example

```python
def logger(func):

    def wrapper():
        print("Before")

        func()

        print("After")

    return wrapper
```

Using Decorator

```python
@logger
def hello():
    print("Hello")
```

Equivalent

```python
hello = logger(hello)
```

Output

```
Before
Hello
After
```

---

## Why Decorators?

Common Uses

- Logging
- Authentication
- Authorization
- Validation
- Timing
- Caching
- Retry Logic

---

## Decorator with Arguments

```python
def logger(func):

    def wrapper(*args, **kwargs):
        print("Calling Function")
        return func(*args, **kwargs)

    return wrapper
```

This works with any function regardless of the number of parameters.

---

## Multiple Decorators

```python
@decorator1
@decorator2
def test():
    pass
```

Execution Order

```
decorator1
    ↓
decorator2
    ↓
test()
```

# 5. Closures

A closure is an inner function that remembers variables from its outer function even after the outer function has finished executing.

Example

```python
def outer(message):

    def inner():
        print(message)

    return inner
```

Usage

```python
hello = outer("Hello")

hello()
```

Output

```
Hello
```

The variable `message` still exists even though `outer()` has already completed.

---

## Why Closures?

Closures are commonly used in

- Decorators
- Callback Functions
- Event Handling
- Function Factories

# 6. Namespaces & LEGB Rule

A namespace is simply a mapping between variable names and objects.

Python searches variables using the LEGB rule.

```
L → Local

E → Enclosing

G → Global

B → Built-in
```

Example

```python
x = 100

def outer():

    x = 50

    def inner():
        x = 20
        print(x)

    inner()
```

Output

```
20
```

Python first checks

1. Local
2. Enclosing
3. Global
4. Built-in

---

## Global Keyword

```python
count = 0

def increment():
    global count
    count += 1
```

Avoid excessive use of `global`.

---

## Nonlocal Keyword

Used to modify variables from the enclosing function.

```python
def outer():

    x = 10

    def inner():
        nonlocal x
        x = 20

    inner()
```

# 7. Functional Programming

Python supports functional programming through built-in functions.

---

## map()

Applies a function to every element.

```python
numbers = [1,2,3,4]

result = list(map(lambda x: x*x, numbers))
```

Output

```python
[1,4,9,16]
```

---

## filter()

Returns elements satisfying a condition.

```python
numbers = [1,2,3,4,5,6]

even = list(filter(lambda x: x%2==0, numbers))
```

Output

```python
[2,4,6]
```

---

## reduce()

Available in

```python
functools
```

Example

```python
from functools import reduce

numbers = [1,2,3,4]

result = reduce(lambda a,b: a+b, numbers)
```

Output

```
10
```

---

## Lambda Functions

Anonymous one-line functions.

```python
square = lambda x: x*x

print(square(5))
```

Output

```
25
```

Lambda functions are commonly used with

- map()
- filter()
- reduce()
- sorted()

# 10. any() & all()

## any()

Returns True if **at least one** element is True.

```python
values = [False, False, True]

print(any(values))
```

Output

```
True
```

---

## all()

Returns True only if **every** element is True.

```python
values = [True, True, False]

print(all(values))
```

Output

```
False
```

---

## Common Use Cases

```python
all(x > 0 for x in numbers)

any(x < 0 for x in numbers)
```

# 12. Context Managers

Context Managers automatically manage resources.

Most common example

```python
with open("data.txt") as file:
    print(file.read())
```

Advantages

- Automatically closes files
- Cleaner code
- Handles exceptions safely

---

## Creating Custom Context Manager

A context manager implements

```python
__enter__()

__exit__()
```

Example

```python
class FileManager:

    def __enter__(self):
        print("Opened")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Closed")
```

Usage

```python
with FileManager():
    print("Working")
```

Output

```
Opened
Working
Closed
```

## Walrus Operator (:=)

Introduced in Python 3.8.

Allows assignment inside expressions.

Example

```python
while (line := file.readline()):
    print(line)
```

Instead of

```python
line = file.readline()

while line:
    print(line)
    line = file.readline()
```

Useful for concise loops but avoid overusing it.

---

## EAFP Principle

Python follows **EAFP**:

> Easier to Ask Forgiveness than Permission.

Instead of checking first,

```python
if key in student:
    print(student[key])
```

Python often prefers

```python
try:
    print(student[key])
except KeyError:
    ...
```

This is considered more Pythonic in many situations.

---

## LBYL Principle

**LBYL** stands for

> Look Before You Leap

This is more common in languages like Java.

Python supports both approaches, but EAFP is generally preferred.
