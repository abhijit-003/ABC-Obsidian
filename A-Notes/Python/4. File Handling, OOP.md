# 1. File Handling

Python provides built-in support for reading and writing files.

## Opening Files

```python
file = open("data.txt")
```

### File Modes

| Mode | Description |
|------|-------------|
| `r` | Read (Default) |
| `w` | Write (Overwrite existing file) |
| `a` | Append |
| `x` | Create new file |
| `rb` | Read Binary |
| `wb` | Write Binary |
| `r+` | Read & Write |

### File Handling common methods
```python
open()         # opens a file and returns a file object
close()        # closes the file
read()         # reads the entire file (or specified number of characters)
readline()     # reads one line from the file
readlines()    # reads all lines and returns them as a list

write()        # writes a string to the file
writelines()   # writes a list (or iterable) of strings to the file

seek()         # moves the file pointer to a specified position
tell()         # returns the current position of the file pointer
truncate()     # resizes the file to a specified size

flush()        # flushes the internal buffer and writes data to the file
fileno()       # returns the file descriptor (integer)
isatty()       # returns True if the file is connected to a terminal
readable()     # returns True if the file is readable
writable()     # returns True if the file is writable
seekable()     # returns True if the file supports random access (seek)

detach()       # separates the underlying binary buffer (text files only)
readinto()     # reads bytes directly into a writable buffer (binary files)

__enter__()    # enters the runtime context (used with 'with' statement)
__exit__()     # exits the runtime context and closes the file
```

---

## Reading Entire File

```python
file = open("data.txt", "r")

content = file.read()

print(content)

file.close()
```

---

## Reading One Line

```python
file.readline()
```

Returns one line at a time.

---

## Reading All Lines

```python
lines = file.readlines()

print(lines)
```

Output

```python
[
    "Line 1\n",
    "Line 2\n",
    "Line 3\n"
]
```

---

## Reading Line by Line (Recommended)

```python
with open("data.txt") as file:
    for line in file:
        print(line)
```

This is memory efficient and recommended for large files.

---

## Writing to File

```python
with open("data.txt", "w") as file:
    file.write("Hello World")
```

**Note:** `w` mode deletes existing content before writing.

---

## Appending to File

```python
with open("data.txt", "a") as file:
    file.write("\nNew Line")
```

Appends new content without deleting old content.

---

## Why use `with`?

Instead of

```python
file = open("data.txt")

# work

file.close()
```

Use

```python
with open("data.txt") as file:
    print(file.read())
```

### Advantages

- Automatically closes file
- Prevents resource leaks
- Cleaner code
- Exception safe

## Constructor (`__init__`)

A constructor in Python is a special method that is automatically called when an object is created. It is mainly used to initialize the object's attributes (set initial values).
Constructor is automatically called whenever an object is created.

```python
class Student:

    def __init__(self, name):
        self.name = name
```

Creating Object

```python
student = Student("Abhi")
```

---

## self

`self` refers to the current object.

```python
class Student:

    def __init__(self, name):
        self.name = name
```

Every instance method must have `self` as its first parameter.

---

## Instance Variables

Variables that belong to each object separately.

```python
class Student:

    def __init__(self, name):
        self.name = name
```

Each object has its own `name`.
Class is the blue print, while object uses that blue print to create the multiple entity.

---

## Instance Methods

```python
class Student:

    def display(self):
        print(self.name)
```

Calling

```python
student.display()
```

---

## Class Variables

Shared among all objects.

```python
class Student:

    school = "ABC School"
```

Access

```python
print(Student.school)
```

### Difference

Instance Variable

- One copy per object

Class Variable

- One copy shared among all objects

---

## Class Methods

Operate on class variables.
This method will be sharing among all the objects.

```python
class Student:

    school = "ABC"

    @classmethod
    def show_school(cls):
        print(cls.school)
```

- Uses `cls`
- Accesses class variables

---

## Static Methods

Independent methods that don't access object or class data.

```python
class Math:

    @staticmethod
    def add(a, b):
        return a + b
```

Calling

```python
Math.add(10, 20)
```

---

### Summary

| Method Type | First Parameter | Access |
|-------------|----------------|--------|
| Instance Method | `self` | Object Data |
| Class Method | `cls` | Class Data |
| Static Method | None | Independent Utility |

# 3. Inheritance

Allows one class to reuse another class.

```python
class Animal:

    def sound(self):
        print("Animal")

class Dog(Animal):
    pass
```

Dog inherits everything from Animal.

---

## Method Overriding

```python
class Animal:

    def sound(self):
        print("Animal")

class Dog(Animal):

    def sound(self):
        print("Bark")
```

Child class replaces parent implementation.

---

## super()

- Used to call parent class methods.
- super() is used to call methods of the parent class from the child class.
- It is commonly used to call the parent's constructor (__init__()).

```python
class Animal:

    def __init__(self, name):
        self.name = name

class Dog(Animal):

    def __init__(self, name, breed):

        super().__init__(name)

        self.breed = breed
```
#### Calling Parent Methods

```python
class Parent:
    def display(self):
        print("Parent Display")

class Child(Parent):
    def display(self):
        super().display()
        print("Child Display")

c = Child()
c.display()
```

---

## Multiple Inheritance

Python supports multiple inheritance.

```python
class A:
    pass

class B:
    pass

class C(A, B):
    pass
```

---

## MRO (Method Resolution Order)

- Python supports multiple inheritance, so the diamond problem can occur, but Python automatically resolves it using Method Resolution Order (MRO).
- Shows the order Python follows to search methods.
- This basically resolve the Diamond problem which occurs in multiple inheritance
#### Diamond Problem:
- The Diamond Problem in Java is an ambiguity that occurs when a class inherits the same method from two different parent classes, and Java cannot determine which implementation to use


```python
print(C.mro())
```

Example:

```python
class A:
    def show(self):
        print("A")

class B(A):
    def show(self):
        print("B")

class C(A):
    def show(self):
        print("C")

class D(B, C):
    pass

d = D()
d.show()
```

output:

```
B
```

Why did it print B?

- Python follows the MRO, which determines the order in which classes are searched for methods.

```python
print(D.__mro__)
```

Output:

```python
(<class '__main__.D'>,
 <class '__main__.B'>,
 <class '__main__.C'>,
 <class '__main__.A'>,
 <class 'object'>)
```

Python searches in this order:

1. D
2. B ✅ (show() found here)
3. C
4. A
5. object

Since B comes before C, Python calls B.show().

# 4. Encapsulation

Encapsulation is the process of wrapping data (variables) and methods (functions) into a single unit (class) and controlling access to the data.
Python follows conventions instead of strict access control.

## 4.1 Access Modifiers

### 1. Public Members

Accessible from anywhere.

```python
class Student:
    def __init__(self):
        self.name = "Abhi"

s = Student()
print(s.name)
```

Output:

```
Abhi
```
### 2. Protected Variable (Convention) (`_`)

```python
self._name
```

A single underscore (`_`) means:

> "This is intended for internal use. Please don't access it from outside."

```python
class Student:
    def __init__(self):
        self._age = 24

s = Student()
print(s._age)

```
This works, but it's a convention that other developers should treat it as non-public.

---

### 3. Private Variable (Name Mangling)(`__`)

```python
self.__salary
```

Python internally changes it to

```python
_ClassName__salary
```

This is called **Name Mangling**.

> Double underscore (__) triggers name mangling.

```python
class Student:
    def __init__(self):
        self.__salary = 50000

s = Student()

print(s.__salary)
```

Output:

```python
AttributeError
```

Python changes the variable name internally.

```python
print(s._Student__salary)
```

Output:

```python
50000
```

So it is not truly private, but it is harder to access accidentally.

# Duck Typing

Duck typing is a feature of Python where the type of an object doesn't matter. What matters is whether the object has the required methods or attributes
"If it behaves like the required object, Python accepts it."

```python
class Dog:

    def speak(self):
        print("Bark")

class Human:

    def speak(self):
        print("Hello")

def talk(obj):
    obj.speak()

talk(Dog())
talk(Human())
```

Notice that `talk` doesn't care whether the object is a `Dog` or a `Human`. It only requires that the object has a `speak()` method
Python only checks whether the object has the required method.

# 6. Abstraction

Used to force child classes to implement required methods.

```python
from abc import ABC, abstractmethod

class Animal(ABC):

    @abstractmethod
    def sound(self):
        pass
```

Any subclass must implement `sound()`.

# 7. Properties

Properties allow controlled access to attributes.

```python
class Student:

    def __init__(self):
        self._name = ""

    @property
    def name(self):
        return self._name

    @name.setter
    def name(self, value):
        self._name = value
```

Usage

```python
student.name = "Abhi"

print(student.name)
```

# 8. Magic Methods (Dunder Methods)

Special methods automatically called by Python.

---

## `__str__()`

Controls output of `print(object)`.

```python
class Student:

    def __str__(self):
        return "Student Object"

student = Student()

print(student)
```

---

## `__repr__()`

Developer-friendly object representation.

```python
repr(student)
```

---

## `__len__()`

Allows `len(object)`.

```python
class Box:

    def __len__(self):
        return 10

box = Box()

print(len(box))
```

---

## `__eq__()`

Controls `==`.

```python
def __eq__(self, other):
    return self.id == other.id
```

---

## `__lt__()`

Controls `<`.

---

## `__gt__()`

Controls `>`.

---

### Common Magic Methods

| Method | Purpose |
|---------|---------|
| `__init__()` | Constructor |
| `__str__()` | String Representation |
| `__repr__()` | Developer Representation |
| `__len__()` | len() |
| `__eq__()` | == |
| `__lt__()` | < |
| `__gt__()` | > |

# Common Mistakes

## Forgetting `self`

Wrong

```python
class Student:

    def display():
        print("Hello")
```

Correct

```python
class Student:

    def display(self):
        print("Hello")
```

---

## Not Using `with` for Files

Wrong

```python
file = open("data.txt")
```

Correct

```python
with open("data.txt") as file:
    pass
```

---

## Confusing Class Variables with Instance Variables

```python
class Student:

    school = "ABC"

    def __init__(self, name):
        self.name = name
```

- `school` → Shared
- `name` → Separate for every object

---

## Forgetting `super()`

If the parent constructor initializes important variables, always call

```python
super().__init__()
```
