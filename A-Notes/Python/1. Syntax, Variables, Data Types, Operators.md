# Day 1 - Python Basics

## Interactive Terminal (REPL)
REPL = **Read → Eval → Print → Loop**

- **Read** → Reads user input.
- **Eval** → Executes the code.
- **Print** → Displays the result.
- **Loop** → Waits for the next command.

Example:
```python
>>> 5 + 3
8
```

# Introduction to Python

- High-level, interpreted programming language.
- Dynamically Typed.
- Object-Oriented and Functional.
- Cross-platform.
- Large standard library.
- Uses indentation instead of braces.

# Variables

Python automatically determines the variable type.

```python
age = 24
name = "Abhi"
salary = 45000.50
is_student = False
```

This is called **Dynamic Typing**.

## Naming Rules

Valid

```python
age
student_name
_name
salary11
```

Invalid

```python
12num
student-name
class
```

- Cannot start with a number.
- Only letters, digits and `_` are allowed.
- Keywords cannot be used as variable names.

## Primitive vs Non-Primitive

### Primitive Types

Store a single value.

- int
- float
- complex
- bool

### Non-Primitive Types

Store collections or references to objects.

- str
- list
- tuple
- set
- frozenset
- dict
- bytes
- bytearray
- memoryview

> **Note:** Unlike Java, everything in Python is an object. The "primitive/non-primitive" distinction is mainly conceptual.

# Sequence Data Types

## str (String)

```python
name = "Abhi"
name = 'Abhi'
```

Properties

- Ordered
- Immutable
- Supports Indexing
- Supports Slicing

### Common Methods

```python
len()          # gives the length of an object
upper()        # converts all characters to uppercase
lower()        # converts all characters to lowercase
replace()      # replaces one substring with another
split()        # splits a string into a list
join()         # joins elements of an iterable(like a list or tuple) into a single string
find()         # returns the index of the first occurrence of a substring
count()        # counts the occurrences of a substring
strip()        # removes leading and trailing whitespace (or specified characters)
startswith()   # checks if a string starts with a given prefix
endswith()     # checks if a string ends with a given suffix
```

Example

```python
name = "Abhi"

print(name.upper())
print(name.lower())
```

---

## list

```python
numbers = [10, 20, 30]
mixed = [10, "Abhi", True, 3.5]
```

Properties

- Ordered
- Mutable
- Allows Duplicates
- Dynamic Size

### List Comprehension

```python
squares = [i*i for i in range(10)]
```

### Common Methods

```python
append()    # adds a single element to the end of the list
extend()    # adds all elements from another iterable to the list
insert()    # inserts an element at a specified index
remove()    # removes the first occurrence of a specified element
pop()       # removes and returns the element at a given index (last by default)
sort()      # sorts the list in ascending order (by default)
reverse()   # reverses the order of the list
clear()     # removes all elements from the list
copy()      # returns a shallow copy of the list
count()     # returns the number of occurrences of a specified element
index()     # returns the index of the first occurrence of a specified element
```

# Set Data Types

## set

```python
nums = {1,2,3,4}
```

Properties

- Unordered
- Mutable
- No Duplicates
- No Indexing

### Common Methods

```python
add()                   # adds a single element to the set
update()                # adds multiple elements from another iterable to the set
remove()                # removes a specified element (raises an error if not found)
discard()               # removes a specified element (does not raise an error if not found)
pop()                   # removes and returns a random element from the set
clear()                 # removes all elements from the set
copy()                  # returns a shallow copy of the set

union()                 # returns a new set containing all unique elements from both sets
intersection()          # returns a new set containing common elements of both sets
difference()            # returns a new set containing elements present only in the first set
symmetric_difference()  # returns a new set containing elements present in either set but not both

issubset()              # checks if the set is a subset of another set
issuperset()            # checks if the set is a superset of another set
isdisjoint()            # checks if two sets have no common elements
```

---

## frozenset

# Mapping Data Type

## dict

Stores data as **Key : Value**

```python
student = {
    "name": "Abhi",
    "age": 24
}
```

Properties

- Ordered (Python 3.7+)
- Mutable
- Keys must be unique.

### Common Methods

```python
keys()      # returns a view of all keys in the dictionary
values()    # returns a view of all values in the dictionary
items()     # returns a view of all key-value pairs as tuples
get()       # returns the value for a given key (or a default value if the key is not found)
pop()       # removes the specified key and returns its value
update()    # updates the dictionary with key-value pairs from another dictionary or iterable
clear()     # removes all key-value pairs from the dictionary
copy()      # returns a shallow copy of the dictionary
```

# Mutable vs Immutable

## Mutable

Can be modified after creation.

- list
- dict
- set
- bytearray

Example

```python
nums = [1,2,3]
nums.append(4)
```

---

## Immutable

Cannot be modified after creation.

- int
- float
- bool
- complex
- str
- tuple
- frozenset
- bytes

Example

```python
name = "Abhi"

name += "jit"
```

A new string object is created.

# Java vs Python (Quick Comparison)

| Java | Python |
|-------|---------|
| Statically Typed | Dynamically Typed |
| Compilation Required | Interpreted |
| Curly Braces `{}` | Indentation |
| Semicolon Required | Not Required |
| Primitive Types | Everything is an Object |
| Fixed-size int | Unlimited-size int |
| Manual Getter/Setter | Direct Attribute Access |
| Arrays | Lists |
