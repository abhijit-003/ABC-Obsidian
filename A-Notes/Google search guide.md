filetype: <file_type>
- This will give the result which only include specific file type
- eg. filetype: pdf it'll show only pdf result

- This will work as logical operator
- eg "Java Begineer guide" filetype:pdf AND filetype:ppt

- eg. java tutorial after:2020 before:2022
