
Upgrade or update node js
- clear the npm cache
```
sudo npm cache clean -f
```

- Install n module globaly
- The "n" module is a popular Node Version Manager (NVM) used to install and switch between different Node.js versions on macOS and Linux systems. It is installed as a global npm package
```
sudo npm install -g n
```
- Install or update the Node version
- For table :
```
sudo n stable
```
- For Latest
```
sudo n latest 
```
- For specific
```
sudo n <version> 
```
