- NPM packages are product specific. i'e the packages need for frontend should be install in client and packages need for backend should be install in server.
- Each folder has it's own package.json
- frontend : npm install axios react-router-dom
- backend: npm install express

#### to start client
```
cd client
npm start
```

Client
```
npm install express mysql2 cors dotenv nodemon
```
### These are **backend dependencies**:

- **express** → backend server framework
- **mysql2** → connect Node to MySQL database
- **cors** → allow frontend (React) to call backend APIs
- **dotenv** → manage environment variables (DB password etc.)
- **nodemon** → auto-restart server during development
