## Memory
#### RAM (Random Access Memory): Temporary memory
- SRAM : STATIC RANDOM ACCESS MEMORY
	- fast and expensive
	- High speed application
- DRAM : DYNAMIC RANDOM ACCESS MEMORY
	- lower speed and cheap
#### ROM (Read-Only Memory): Store permanent data
- Firmware
	- Defines how hardware devices communicate with each other
- BIOS (Basic Input Output System):
	- responsible for starting the system and handover the system to OS
## Storage
#### HDD (Hard Disk Drives)
- Introduced by IBM in 1956
- Cheap
- Slower than SSD
#### SSD (Solid State Drives)
- uses NAND-based flash memory (No moving parts),
- provide faster data access
- reduce power consumption
- Higher cost
- Types of SSD (these types are bases on speed):
	- NVMe: Non-Volatile Memory Express
		- Higher performance
		- They connect directly to the CPU via PCIe lanes
		- This allows faster data transfer compared to SATA-based SSDs
	- SATA SSD: (Serial Data Technology)
		- Older and slower
		- SATA : The interface technology used to connect devices
